# **App Name**: fldr.ux

## Core Features:

- Visual Logic Editor: Drag and drop interface to create logic flows by connecting nodes with wires. Offers intuitive manipulation of nodes and connections.
- Node Library: A set of pre-built nodes representing actions, triggers, and logic operations. Includes a variety of node types for diverse functionalities.
- Smart Connection Suggestions: Suggest valid connection points between nodes based on their types and compatibility. Uses an AI tool to determine context and relevance, enhancing workflow efficiency.
- Action Initialization: Set custom properties like 'Identity', 'Payload Schema' and custom icons for registered actions, logic and trigger components. Allows extensive customization of node attributes.
- Code Generation: Generate executable Javascript code based on the visual logic flow for the client. Uses an AI tool to translate visual diagrams into functional code.
- Node Customization: Add custom Javascript code or functions to nodes. Code is stored in a serverless compute such as Cloud Functions. Provides a robust system for extending node capabilities.
- Exporting Flows: Export entire logic flows for versioning and sharing. Enables collaboration and code management.

## Style Guidelines:

- Primary color: Electric Purple (#BE79DF) to evoke innovation and power.
- Background color: Soft Lavender (#F4F0FB), a very desaturated tint of the purple primary color, provides a soothing and unobtrusive backdrop.
- Accent color: Golden Yellow (#D6A800), an analogous color offering strong contrast and visual interest. Use sparingly for important interactive elements like buttons.
- Headline font: 'Space Grotesk' sans-serif for headlines, lending a techy but modern touch.
- Body font: 'Inter' sans-serif for body text, a grotesque-style font giving a neutral modern look.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use clean, geometric icons from Lucide to represent actions, triggers, and logic components.
- Arrange the canvas in a grid-based layout for precise alignment of nodes and wires.
- Employ subtle animations and transitions to indicate connections, selections, and actions.
